What an automated check covers

Weekly and on-demand axe-core checks cover the rendered public pages listed in the report. Keyboard, screen-reader and human testing can reveal other barriers.

01

Same page, same check

Changes compare the same requested and final URL, axe version, browser, viewport and rules. Missing pages, incomplete resource loads and incompatible profiles stay unassessed. A changed element selector may appear as one resolved and one introduced finding.

02

Understand the categories

Findings are automated rule failures. “Needs review” means axe could not decide. Best-practice tags are distinct from WCAG criteria. Neither zero findings nor a resolved item proves conformance.

03

Keep the useful evidence

Receipts contain rule names, impacts, WCAG tags and element selectors. Published captures omit raw HTML and check payloads. Selectors can contain public attribute values. Imports stay in memory until you close or reload this page; use Save receipt to keep them.
